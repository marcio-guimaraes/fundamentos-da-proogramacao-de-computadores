# Resolução de Questões de Programação

Este repositório contém a resolução das questões propostas no livro *"Fundamentos da Programação de Computadores: Algoritmos, Pascal, C, C++ e Java"* de *Ana Ascencio* e *Edilene Campos. Todas as soluções foram implementadas na linguagem **C*.

O livro utilizado como base para os exercícios pode ser acessado através deste [link](https://archive.org/details/fundamentos-da-programacao-de-computadores-algoritmos-pascal-c-c-padrao-ansi-e-java-pdfdrive).

## Estrutura do Repositório

O conteúdo está organizado em pastas, cada uma correspondendo a um capítulo do livro:

-   [*Capítulo 3*: Estrutura Sequencial](./Cap03.Estrutura-sequencial)
-   [*Capítulo 4*: Estrutura Condicional](./Cap04.Estrutura-condicional)
-   [*Capítulo 5*: Estrutura de Repetição](./Cap05.Estrutura-de-repeticao)
-   [*Capítulo 6*: Vetores](./Cap06.Vetores)
-   [*Capítulo 7*: Matrizes](./Cap07.Matrizes)
-   [*Capítulo 8*: Sub-rotinas](./Cap08.Sub-rotina)
-   [*Capítulo 9*: Manipulando Sequência de Caracteres](./Cap09.Manipulando-sequencia-de-carcteres)
-   [*Capítulo 10*: Registro](./Cap10.Registro)
-   [*Capítulo 11*: Arquivos](./Cap11.Arquivos)
